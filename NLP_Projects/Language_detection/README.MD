******* Project Name *******
Language Detection System


%%%%%%%% Project Overview%%%%%%%%%

Language Detection System that accepts text as input and predicts the language in which the text is written.

LD system takes text as input, processes and transforms the text into numerical features using TF-IDF, and uses a Machine Learning classification model to predict the language.

Input Text : Hello, how are you?
Detected language : English
